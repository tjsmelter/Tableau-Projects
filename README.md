# Airbnb Project Seattle

Created interactive Tableau dashboard which includes several relevant metrics for Airbnb real estate data from Seattle, including: sales performance across regions, product categories, and time periods. Project designed with the intent to help enable stakeholders to identify key revenue drivers, monitor trends, and uncover actionable insights to support decision-making. Data is from Kaggle.com
